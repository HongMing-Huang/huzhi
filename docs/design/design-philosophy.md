# 设计哲学：证据的沉默（Evidentiary Silence）

> 本文用 canvas-design 的方法产出，但落点不是海报，而是**可执行的界面语言**。
> 前半部分是哲学，后半部分是它在代码里的具体形态。

---

## 一、宣言

### 证据的沉默

判断是一种安静的行为。

在这个产品里，人要做的事只有一件：读一段文字，然后决定它出自谁手。
这个动作不需要被鼓励、被庆祝、被色彩包围。它需要的是**不被打扰**。

因此整个界面的第一原则是：**证据发声，界面沉默**。

文字是唯一的主角。所有不是文字的东西——边框、阴影、色块、图标、动效——
都只有一个职责：让文字更容易被看清，然后消失在背景里。
任何一个装饰元素如果不能通过"它帮助了判断吗"这一问，就应当被删除。

这不是极简主义的口号。这是功能上的必要：当读者在分辨一段话是人写的还是机器写的，
任何一处多余的视觉噪声，都在消耗他本该用于分辨的注意力。

### 空间即层级

不用线条分隔，用呼吸分隔。

内容与内容之间的关系，由它们之间的距离决定，而不是由包裹它们的盒子决定。
两段相关的文字靠得近，两段无关的文字离得远——读者不需要看见边框就能理解结构。
这要求间距系统必须是**有节奏的**：4 / 8 / 12 / 16 / 20 / 24 / 32，
每一次跨越都意味着关系的一次改变，而不是随手写下的数字。

卡片存在的唯一理由是承载一组真正独立的信息。如果一组内容本就属于主流，
给它加一个白底和边框，只会制造虚假的分离感。

### 色彩即判断

这个产品里只有一种彩色是有意义的：**蓝色，代表可以行动**。

蓝色不用于装饰、不用于强调情绪、不用于区分板块。它只出现在
"你现在可以点这里做一个判断"的位置。读者看见蓝色，就知道那是一个决定。
当页面上出现第二种、第三种彩色时，蓝色就失去了这个含义。

其余一切都是灰阶：主文字最深，次级信息退后一层，元信息再退一层，
分隔线几乎看不见。四级灰阶足以表达任何层级关系——
如果四级不够，说明信息结构本身出了问题，应该去改结构而不是加颜色。

红色与橙色保留给两种情形：判断错误，以及伪装者现形。它们必须罕见，
罕见才有分量。

### 克制的动作

界面上的动作只有三种重量。

**主行动**：一个页面最多一个。它是实心的、蓝色的，读者一眼就该找到它。
**次行动**：描边或浅底，它们是"也可以做但不是现在该做的事"。
**文本行动**：没有边框，只是一段可点的灰字。赞同、评论、收藏都属于此类——
它们是社交礼节，不是判断本身，因此不该抢走主行动的位置。

按钮的尺寸不该有第四种。三档就足够：常规 34px，紧凑 30px，
以及页面级主按钮 36px。每多一档，一致性就少一分。

### 时间的分寸

动效存在的意义是解释状态的变化，不是展示技巧。

一次点击的反馈在 200 毫秒内完成，因为人对操作响应的耐心就这么长。
一次状态切换给 300 毫秒，让读者看清"它从什么变成了什么"。
一次内容展开可以慢一些，800 毫秒，因为那是阅读的节奏而非操作的节奏。

所有位移不超过 8 像素。超过这个数，动效就从"暗示"变成了"表演"。
不使用弹跳、不使用过冲、不使用旋转——它们在一个要求冷静的界面里
只会制造轻浮感。

### 手艺的证据

这一切之所以成立，靠的是大量看不见的校准。

一个按钮的内边距为什么是 0 12px 而不是 0 14px；
为什么赞同数是 tabular-nums 而不是比例数字；
为什么折叠正文用遮罩渐隐而不是硬截断——
每一个决定背后都有一次具体的取舍。

真正的克制不是少做，而是**做了很多次删减之后剩下的东西**。
界面看起来毫不费力，恰恰是因为在每一处都费过力。
这是这份设计语言唯一想传达的态度：**不表演精致，只呈现可信**。

## 二、落到代码：设计 token 与组件规格

### 2.1 间距节奏

```
4px   元素内部的最小缝隙（图标与文字之间）
8px   紧密关联的两个元素
12px  同一组内的元素
16px  一组内容的内边距
20px  卡片的标准内边距（官方 --zhc-padding-horizontal）
24px  动作项之间（官方 .ContentItem-action margin-left）
32px  区块与区块之间
```

**规则**：不使用节奏之外的数值。需要 18px 时，问自己是 16 还是 20。

### 2.2 灰阶四级

| 层级 | token | 值 | 用途 |
|---|---|---|---|
| L1 主文字 | `--ink` | `#191b1f` | 标题、正文 |
| L2 次级 | `--ink-2` | `#373a40` | 作者名、卡片标题 |
| L3 元信息 | `--meta` | `#535861` | 说明文字、动作行 |
| L4 弱提示 | `--time` | `#81858f` | 时间戳、辅助说明 |
| 分隔 | `--divider` | `#f8f8fa` | 几乎不可见的线 |

**规则**：正文永远 L1，不允许用 L3 写正文；弱提示不承载必读信息。

### 2.3 动作三层级

| 层级 | 类名 | 形态 | 每页数量 |
|---|---|---|---|
| 主行动 | `.btn-primary` | 实心蓝 + 白字 | **最多 1 个** |
| 次行动 | `.btn-outline` / `.btn-soft` | 描边蓝 / 10% 蓝底 | 不限但需克制 |
| 文本行动 | `.content-action` | 无边框灰字 | 用于社交动作 |

**尺寸只有三档**：
- 常规 `line-height: 32px; padding: 0 16px`（总高 34px）
- 紧凑 `line-height: 30px; padding: 0 12px`（信息流内，官方规格）
- 页面主按钮 `height: 36px`（登录页提交按钮，官方规格）

### 2.4 色彩的唯一彩色原则

```
蓝  --zhihu  #1772f6   仅用于"可以行动"
橙  --hot    #f77a31   仅用于"伪装者/热度"
红  --danger #d95350   仅用于"判断错误"
```

**规则**：一个视口内，蓝色元素不超过 5 处。超过说明主次不清。

### 2.5 动效三档

```
--dur-fast    200ms   点击反馈、hover
--dur-state   300ms   状态切换（赞同变实心、揭晓）
--dur-expand  800ms   内容展开
```

**规则**：只用 `opacity` 与 `transform`；位移 ≤8px；不用弹跳与旋转。

### 2.6 自检清单

每次改界面后逐条核对：

- [ ] 这个页面的主行动是唯一的吗？
- [ ] 有没有出现第四种彩色？
- [ ] 间距是否都落在节奏表上？
- [ ] 正文是否用了 L1 灰阶？
- [ ] 动作行的项是否都 `nowrap` 且不折行？
- [ ] 有没有 `opacity:0` 藏起了核心动作？
- [ ] 动效位移是否都 ≤8px？
- [ ] 1280px 宽度下横向溢出是否为 0？
