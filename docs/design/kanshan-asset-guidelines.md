# 刘看山素材使用规范

> 本项目内素材位于 `web/public/kanshan/`。三张 GIF 均为 320×320、透明背景、1:1 比例。比赛授权范围需以知乎活动提供的素材包条款为准；本仓库不把它们作为通用开源素材再授权。

## 角色分工

| 变体 | 页面角色 | 推荐尺寸 | 当前场景 |
|---|---|---:|---|
| `wave.gif` | 欢迎与建立信任 | 128px | 登录页品牌欢迎区 |
| `idle.gif` | 裁判、观察与提示 | 64–80px | 首页活动横幅、帖子详情判断台 |
| `stroll.gif` | 等待、探索与陪伴 | 96px | 1v1 匹配入口 |

## 使用规则

1. 只通过 `web/components/Kanshan.tsx` 使用，禁止页面自行拼素材路径与任意宽高。
2. 保持 1:1、`object-contain`，不裁切、不拉伸、不叠滤镜；最小 64px，最大 128px。
3. 刘看山承担“欢迎、主持、陪伴、提示”之一，不作为普通按钮图标，也不在同一视口重复出现。
4. 有信息含义时填写具体 `alt`；已有相邻文字完整表达含义时使用 `decorative`，避免读屏重复。
5. 动效只使用素材自身 GIF，不再附加大幅位移或循环弹跳；尊重页面现有克制的 140/300/500ms 动效节奏。
6. 移动端空间不足时可隐藏装饰性实例，但不能隐藏必要的规则文本或操作入口。

## 文案语气

刘看山不替产品自夸，也不直接泄露答案。适合提醒“核实经历、观察上下文、别只看句式”，不适合说“这一定是 AI”。这样既保留 IP 亲和力，也不破坏身份博弈。
