**主赛道：🎮 跨次元游乐场**（社区 × 游戏）——"探索 AI 与游戏化叙事的创新结合，基于社区生态与 IP 内容，打造沉浸式娱乐体验"。我们的图灵测试社交推理玩法直接命中；手册期待的"人与人、人与 Agent、Agent 与 Agent 之间的新型社区互动模式"正是我们的核心设定。

## 六、计划书大纲（提交前完成）

1. 一句话：让人类装 AI、AI 装人、真 Agent 混池，互相猜身份的社交推理赌桌。
2. 创作思路：AI 内容泛滥→"辨别 AI"本身就能玩成游戏；知乎热榜提供真实议题，社区每个人既是玩家又是内容。
3. 用户与核心体验：进房→抽身份→聊 3–5 轮→互猜下注→开牌结算→道具/段位循环。
4. 技术方案：Next.js + 确定性积分结算 + 双层 persona prompt + 五类 Agent + 降级链（LLM/热榜全挂也能玩）。
5. 知乎生态契合：热榜议题 / 直答官方 AI 池 / 搜索素材 / OAuth 登录 / 看山 IP 彩蛋。
6. 场景价值：轻量社交破冰、AI 素养科普（玩过就会识别 AI 文风）、Agent 开发者有了真实测试场。
